面向现实的学习 · Learning for Real

探索 AI 可用环境下，学什么、记什么、如何实践与评价，让学习持续转化为现实问题的解决能力。

这是一个从个人问题出发、持续修订的公开文档项目。后续可以逐步积累个人实验、方法库和工具。

## 从这里开始

阅读 [AI 时代该学什么、记什么](docs/learning-and-memory.md)。

文档讨论学习内容的选择、内部记忆与外部资料的分工、传统学习方法的调整，以及相关研究和可试行的实践流程。资料核对截至 2026 年 10 月 9 日。

## 项目的基本方向

- 以真实工具条件下的应用与产出为目标。
- 区分当次作品、可复用系统和后续任务中的持续适应。
- 区分研究结果、实践建议和待检验的假设。
- 保留来源与证据局限，通过实践继续修订。

当前内容是叙述性整理与初步方案，尚未验证为一套普遍有效的学习法。

## 接下来可以做的事

- 用一个真实任务记录质量、总耗时、错误与返工。
- 更换数据或要求，检查流程是否可以复用。
- 根据实践结果修订文档，补充有来源的案例。

欢迎通过 Issues 提出问题、补充研究或指出错误，也可以通过 Pull Requests 建议修改。讨论研究结论时，请尽量附原始来源，并说明研究实际测量了什么。
